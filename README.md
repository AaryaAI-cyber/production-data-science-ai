# Full Stack Data Science & AI — Complete Booklet

A beginner-to-professional learning path: **Python → NumPy → Pandas → Visualization → SQL → EDA → Statistics → Machine Learning → AI apps**.
Every topic has its own folder with a notebook (line-by-line explanations, real-world uses, mini projects), a README and the data it needs.

## Topics
| # | Topic | What's inside |

## Run locally
```
git clone <this-repo-url>
cd fsds-ai-booklet
pip install -r requirements.txt
cd 01_python_history_and_installation
jupyter notebook
```
Notebooks are independent: open any folder and run its notebook.
